How to Use This Library


Quest Selection
This library contains 144 quests organized across eight skill domains and seven levels. Not all quests need to be completed — these are options. Target 1–2 quests per week, with flexibility to repeat, skip, or substitute.
Domain Proficiency Framework
Each domain tracks proficiency independently. A player might be Journeyman in Daily Living but Novice in Social Skills. This prevents the illusion that system-wide level advancement means uniform readiness.

Selection Guidelines
Balance across domains: Rotate through all 8 over time. Don't let the player only pick comfortable domains.
Match to readiness: If a Level 3 quest is too hard in one domain, drop to Level 2. Progress isn't uniform across domains.
Include recovery quests: The "something went wrong, now what?" quests are some of the most important. Don't skip them.
Co-design new quests: These are starting points. The player should be designing quests by Level 3–4.
