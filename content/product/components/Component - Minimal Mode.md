# Component - Minimal Mode

## WHAT: Definition

The Bronze mode that shows only required tasks — due dates, critical responses, and system-generated items. Stack shrinks as tasks complete with no auto-replenishment.

## WHERE: Ecosystem

- Parent: [[System - Bronze Operations]]
- Selected in: [[Feature - Sorting Room]]
- Displayed on: [[The Table - Bronze Position]]

## WHY: Rationale

- System: [[System - Bronze Operations]] — one of three modes
- Driver: High-commitment weeks need minimal operational distraction.

## WHEN: Timeline

Part of Bronze Operations system.

## HOW: Implementation

**Stack behavior:**
- Contains only: due-date items, critical responses, system-generated
- No discretionary tasks
- Task completes → stack shrinks (no replenishment)

**Best for:** Weeks with heavy Gold/Silver commitment, recovery periods, intentional operational pause.
